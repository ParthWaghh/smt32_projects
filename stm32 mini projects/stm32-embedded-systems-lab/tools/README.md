# Tools

Utility scripts for log parsing, test automation, and data analysis across the embedded lab.

## Contents

| Script | Purpose | Usage |
|--------|---------|-------|
| `parse_uart_log.py` | Parse raw UART telemetry streams into structured CSV datasets | `python parse_uart_log.py [input_log] [output_csv]` |
| `can_frame_decoder.py` | Decode 11-bit CAN frame logs into physical telemetry units (RPM, speed, temp) | `python can_frame_decoder.py [can_log_file]` |

## Directory: `test-results/`

Automated test output files, parsed CSV records, and regression logs generated by local test automation scripts.
